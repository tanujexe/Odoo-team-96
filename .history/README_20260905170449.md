# PeoplePay360

HR and payroll management application with a React frontend, Node.js/Express backend, and MongoDB database.

## Quick Start

### Requirements

- Node.js 18 or newer
- npm 9 or newer
- A MongoDB Atlas account and cluster

### Install

From the project root:

```bash
npm install
copy .env.example .env
```

On macOS/Linux, use `cp .env.example .env` instead of the `copy` command.

### Connect MongoDB Atlas

1. Sign in to [MongoDB Atlas](https://www.mongodb.com/atlas) and create a free cluster.
2. Open **Database Access** and create a database user. Save the username and password.
3. Open **Network Access**, add your current IP address, and wait for the rule to become active.
4. Open **Database**, select **Connect > Drivers**, choose **Node.js**, and copy the connection string.
5. In the root `.env` file, replace the local URI with your Atlas URI:

```env
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster-url>/peoplepay360?retryWrites=true&w=majority
```

Replace `<username>`, `<password>`, and `<cluster-url>` with your Atlas values. If the password contains characters such as `@`, `#`, or `/`, URL-encode them first. Keep `.env` private and never commit it.

### Run the application

Start the backend and frontend together:

```bash
npm run dev
```

Open the frontend at `http://localhost:5173`.
The backend runs at `http://localhost:5000`.

The backend connects to Atlas when it starts. If the connection fails, check the Atlas IP allowlist, database credentials, and `MONGODB_URI`.

### Optional: Add sample data

```bash
npm run seed
```

### Tests

```bash
npm run test:server
npm run test:client
```

The main folders are `client/` for the frontend, `server/` for the backend, and `docs/` for project documentation.
